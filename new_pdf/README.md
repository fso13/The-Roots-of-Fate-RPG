# PDF «Корни судьбы» (новая сборка)

Сборка: `npm run pdf:new`

| Файл | Содержание |
|------|------------|
| `kniga-igroka.pdf` | Книга игрока (A5, стиль Cairn) |
| `kniga-hranitelya.pdf` | Книга хранителя (A5, стиль Cairn) |
| `polnoe-izdanie.pdf` | Игрок + хранитель + модули: магия, огнестрел, транспорт, нуар |
| `modules/*.pdf` | Остальные модули по группам (Gothic, Skyrim, Elden Ring, Homm3…) |
| `adventures/*.pdf` | Каждое приключение отдельно (A5, белый фон, шрифты и цвета как у книги игрока; иллюстрации по миру) |

Оглавление полного издания: **Для игрока** · **Для хранителя** · **Модули**.

### Стили приключений

Обложка и текст — **как книга игрока** (белый фон, Exocet / Lora, золотой акцент). Жанр задаёт **иллюстрации**, не цвет страницы.
