# PDF The Edge! (new_pdf)

Сборка: `npm run pdf:new`  
Брошюры A4: `npm run pdf:broshyura`

| Файл | Содержание |
|------|------------|
| `kniga-igroka.pdf` | Книга игрока (A5, чтение / печать постранично) |
| `kniga-hranitelya.pdf` | Книга хранителя (A5) |
| `polnoe-izdanie.pdf` | Игрок + хранитель + модули: магия, огнестрел, транспорт, нуар |
| `*-broshyura.pdf` | То же, **импозиция под брошюру** (A4 landscape, 2 страницы на лист) |
| `list-personazha.pdf` | Лист персонажа (A5 бланк) |
| `modules/*.pdf` | Пакы модулей (Gothic, Skyrim, Elden Ring, Homm3…) |
| `adventures/*.pdf` | Приключения отдельно |

Сайт подхватывает эти файлы в `public/new_pdf/` при `npm run build`.

### Печать брошюры

Печатать файл `*-broshyura.pdf`, не обычный A5:

1. Формат **A4**, ориентация как в файле (альбомная).
2. **Двусторонняя** печать, переворот по **короткому** краю.
3. Режим «брошюра / booklet» в драйвере **выключить** — страницы уже спущены.
4. Сложить стопку пополам и сшить по сгибу.

Обложка и задник — **full-bleed**. Число страниц A5-книги кратно **4** (листы «Заметки» при необходимости).
