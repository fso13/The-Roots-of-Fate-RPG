# Модуль: «Heroes III — лор Антагарича»

*Краткий справочник по миру **Heroes of Might and Magic III** для обычной партии приключенцев: фракции, конфликты, места, имена и то, как встроить героев в Эрафию через личные сцены.*

## 0. Коротко

- **Антагарич** — материк, где Эрафия пытается удержать порядок после войн, вторжений демонов и некромантских заговоров.
- **Герои игроков** — не полководцы на глобальной карте, а отряд, который решает опасные дела лично: переговоры, разведка, руины, чудовища, магические катастрофы.
- **Фракции** дают фон, союзников, врагов и моральные выборы.
- **Лор** нужен, чтобы сцены звучали как Heroes III: грифоны на башнях, эльфийские чащи, башни магов, порталы Инферно, холод Некрополиса.

---

## 1. Тон мира

Антагарич яркий, но не безопасный. На одной дороге можно встретить рыцаря Эрафии, эльфийского посла, торговца артефактами и скелета-разведчика, который помнит имя убийцы лучше живых свидетелей.

Используйте три темы:

- **Наследие войны:** старые битвы оставили руины, проклятия, потерянные знамёна и бесхозные артефакты.
- **Фракционная честь:** почти каждый NPC кому-то служит, даже если говорит «я сам по себе».
- **Магия как часть быта:** колодцы маны, обелиски, големы, святилища и проклятые дороги встречаются чаще, чем в низком фэнтези.

## 3. Фракции как источник приключений

Фракция в этом модуле отвечает на вопросы: **кто просит помощи, кто мешает, какую цену требует союз**.

### 3.1. Замок

**Люди, грифоны, монахи, рыцари, ангелы.**  
Тон: долг, корона, честь, защита слабых.

| | |
|--|--|
| **Просит** | вернуть святыню, найти пропавшего рыцаря, разоблачить предателя |
| **Мешает** | требует закона там, где нужен компромисс |
| **Цена союза** | клятва, публичное имя, отказ от некромантии и демонических сделок |
| **Навыки** | Дипломатия, Этикет, Право и обычай, Религия |

### 3.2. Оплот

**Эльфы, гномы, дендроиды, единороги, зелёные драконы.**  
Тон: древний лес, память, границы, осторожность.

| | |
|--|--|
| **Просит** | очистить рощу, вернуть украденный росток, остановить охотника на единорогов |
| **Мешает** | скрывает тропы и правду от «короткоживущих» |
| **Цена союза** | уважение к земле, обещание не рубить священные деревья |
| **Навыки** | Природа, Выживание, Внимание, Дипломатия |

### 3.3. Башня

**Маги, гремлины, големы, джинны, титаны.**  
Тон: знание, холодная логика, магические испытания.

| | |
|--|--|
| **Просит** | добыть фрагмент артефакта, остановить сбой голема, проверить руины |
| **Мешает** | считает риск приемлемым, если эксперимент важен |
| **Цена союза** | образец, отчёт, право первым изучить находку |
| **Навыки** | Магические знания, Анализ, Ремесло, Проницательность |

### 3.4. Инферно

**Бесы, демоны, церберы, ефриты, дьяволы.**  
Тон: искушение, пожар, договор, вторжение.

| | |
|--|--|
| **Просит** | «малую услугу» за большую награду |
| **Мешает** | делает конфликт проще, но грязнее |
| **Цена союза** | имя, кровь, нарушение клятвы, открытая дверь |
| **Навыки** | Воля, Магические знания, Проницательность, Религия |

### 3.5. Некрополис

**Скелеты, зомби, вампиры, личи, костяные драконы.**  
Тон: холод, бессмертие, память мёртвых.

| | |
|--|--|
| **Просит** | вернуть тело, открыть склеп, найти древнюю клятву |
| **Мешает** | говорит правду так, что она звучит как угроза |
| **Цена союза** | запрет на погребение, молчание, ритуальный долг |
| **Навыки** | Религия, История, Медицина, Воля |

### 3.6. Темница

**Троглодиты, гарпии, медузы, минотавры, чёрные драконы.**  
Тон: подземные города, сила, тайные рынки.

| | |
|--|--|
| **Просит** | провести через тоннели, украсть печать, освободить гладиатора |
| **Мешает** | уважает только силу, долг и выгоду |
| **Цена союза** | трофей, тайна, поединок или услуга внизу |
| **Навыки** | Запугивание, Скрытность, Внимание, Атлетика |

### 3.7. Цитадель

**Гоблины, орки, огры, виверны, циклопы.**  
Тон: выживание, племя, трофеи, прямота.

| | |
|--|--|
| **Просит** | доказать силу, вернуть украденный трофей, снять проклятие с вождя |
| **Мешает** | не доверяет «красивым словам» без дела |
| **Цена союза** | честный бой, добыча, уважение к вождю |
| **Навыки** | Атлетика, Запугивание, Выживание, Дипломатия |

### 3.8. Крепость

**Ящеры, змеи, василиски, горгоны, гидры.**  
Тон: болото, терпение, яды, древние племена.

| | |
|--|--|
| **Просит** | не дать чужакам осушить топь, вернуть кладку яиц, остановить яд |
| **Мешает** | проверяет чужаков ловушками и молчанием |
| **Цена союза** | уважение к болотам, противоядие, клятва не вести войска |
| **Навыки** | Природа, Выживание, Алхимия, Внимание |

### 3.9. Сопряжение

**Элементали, феи, фениксы.**  
Тон: стихии, равновесие, чуждая логика.

| | |
|--|--|
| **Просит** | вернуть баланс стихий, закрыть разлом, остановить жадного мага |
| **Мешает** | мыслит циклами, а не человеческими жизнями |
| **Цена союза** | отказаться от лишней силы, вернуть артефакт стихии |
| **Навыки** | Магические знания, Природа, Религия, Воля |

## 4. Лорные объекты

| Объект | Что это даёт в приключении |
|--------|----------------------------|
| **Обелиск** | хранит фрагмент тайны: имя, путь, пароль, видение прошлого |
| **Колодец маны** | восстанавливает силы мага, но показывает след последнего заклинания |
| **Святилище** | просит клятву или жертву перед благословением |
| **Гильдия магов** | даёт знание, но требует отчёт и контроль |
| **Грифоний бастион** | место чести, суда и опасной присяги |
| **Подземный рынок** | редкие сведения, рабские сделки, артефакты с чужой кровью |
| **Склеп Дейи** | мёртвые свидетели, опасные ответы, некромантская цена |
| **Роща единорогов** | правда без лжи, если герои выдержат её последствия |

## 6. Шпаргалка

- Держите фокус на партии: что герои видят, с кем говорят, кого спасают, что решают лично.
- Фракции должны звучать ярко, но не заменять персонажей игроков.
- Для правил используйте базовые главы: **магия**, **бестиарий**, **таланты и навыки**.
