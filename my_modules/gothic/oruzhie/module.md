# Модуль: «Готика — оружие»

*Снаряжение колонии в духе **Gothic** (Piranha Bytes): руда как валюта, учителя в лагерях, оружие с **требованием к Телу**. Дополняет [Глава 5. Снаряжение](../../rpg/05-snaryazhenie.md) и [Расширенное снаряжение](../../rpg/fantasy/03-snaryazhenie.md).*

## 0. Коротко

- **Руда** — основная монета; цены ниже в **оригинальных** таблицах.
- У каждого оружия есть **мин. Тело** — без него атакуете с **−2** к **итогу** (или не можете — по договорённости).
- **Качество** готического клинка: **ржавое / обычное / мастерское / рудное / орочье** → **+0 / +0 / +1 / +1 / +2** к бонусу.
- Навыки учат **тренеры** в лагерях (см. модуль **«Готика — таланты»**).

## 3. Цены в руде (ориентир)

| Качество | Множитель к «обычной» цене из гл. 5 |
|----------|-------------------------------------|
| Ржавое | **×0.5** (или бонус **−1**) |
| Обычное | **×1** |
| Мастерское | **×3** |
| Рудное | **×5** |
| Орочье / уникальное | не продаётся — квест или трофей |

**Стартовое оружие** у заключённого: **дубина** (ржавая) или **ничего** — ведущий решает.

---

## 4. Особые правила

### 4.1. Усталость от тяжёлого оружия

Если **Тело** на **2 ниже** минимума оружия: после **первой** атаки в бою — **1 стресс** (или **−1 ОД** в следующем раунде).

### 4.2. Разоружение

При **критическом** попадании (модуль критов) или таланте **«Обезоружить»** — противник роняет оружие; поднять — **1 ОД** в **Рукопашной**.

### 4.3. Серебро и святость

**Серебряный клинок** (Иннос): **+1** к бонусу против **нежити** и **бесов** раз за сцену. Редок; чинится только в **храме** Старого лагеря.

## Пример из партии: «Рудный обрыв»

**Диего** с **Телом 4** берёт **меч одноручный** (+2): итог **12**, ЧЦ **10** → урон **(12 − 10) + 2 = 4**. Без тренера меча атаковал бы с **−2** к итогу — урон **(10 − 10) + 2 = 2**.
