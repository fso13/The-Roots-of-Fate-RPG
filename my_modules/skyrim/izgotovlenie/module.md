# Модуль: «Скайрим — изготовление»

*Кузнечное дело, плавильня, **улучшение** на наковальне, **зачарование** на алтаре душ. Дополняет [Глава 5. Снаряжение](../../rpg/05-snaryazhenie.md). Связан с **«оружие»**, **«броня»**, **«таланты»**, **«алхимия»** (души для зачарования).*

## 0. Коротко

- **Кузнечное дело** — создать и **улучшить** оружие/броню; нужны **материалы** и **наковальня**.
- **Плавильня** — руда → слитки; **двемерский** металл только в **дварфских руинах**.
- **Зачарование** — **алтарь**, **камень душ**, **разобранный** зачарованный предмет.
- Все проверки: **2d6 + Кузнечное дело** (или **Зачарование**) **≥ ЧЦ** по таблице.

---

## 1. Материалы

| Материал | Источник | Слиток (плавка) |
|----------|----------|-----------------|
| **Железная руда** | шахты, бандиты | **2d6 + плавка ≥ 9** |
| **Сталь** | железо + **уголь** | автоматически при навыке **≥ 1** |
| **Орочье** | орочьи крепости | ЧЦ **10** |
| **Двемерский** | руины, **шестерёнки** | ЧЦ **12** |
| **Эльфийский** | редкий лом | ЧЦ **11** |
| **Стекло** | кристаллы + руда | ЧЦ **13** |
| **Эбонит** | **вулканическое** стекло + руда | ЧЦ **13** |
| **Даэдрическое** | **эбонит** + **сердце даэдра** | ЧЦ **15**, кузня культа |
| **Кость дракона** | трофей дракона | ЧЦ **14**, только **кузня** Компаньонов / квест |

**Кожа / шкура:** дубильня не нужна — **2d6 + Охота ≥ 9** → **1** ед. кожи.

---

## 2. Создание предмета

| Предмет | Материалы | ЧЦ ковки | Время |
|---------|-----------|----------|-------|
| Железный меч | **2** слитка | **9** | сцена |
| Стальной меч | **3** стали | **10** | сцена |
| Стальной доспех (тяж.) | **5** стали + кожа | **11** | **2** сцены |
| Двемерский меч | **3** двемер + **1** кожа | **12** | **2** сцены |
| Стеклянный лук | **2** стекла + **1** древесина | **13** | **2** сцены |
| Даэдрический клинок | **5** эбонит + сердце | **15** | квест + сцена |

**Провал:** **половина** материалов **теряется**; **1 стресс** при ЧЦ **15**.

**Мастер-кузнец** (ранг **4+**): **−1** к ЧЦ (минимум **8**).

---

## 3. Улучшение (наковальня)

| Ступень | Эффект | Материалы | ЧЦ |
|---------|--------|-----------|-----|
| **Улучшение I** | **+1** к бонусу оружия **или** **+1** к ЧЦ брони | **1** слиток материала предмета | **10** |
| **Улучшение II** | ещё **+1** (макс. как **+1** материал**) | **2** слитка | **11** |
| **Улучшение III** | легендарное качество (нарратив) | **3** слитка + **драгоценный** камень | **13** |

*Обычное* железо **не** улучшается выше **I**; **даэдра** — только **I** (уже максимум материала).

**Точильный камень** в кармане: **+1** к **итогу** ковки раз за сессию.

---

## 4. Ремонт

| Урон | ЧЦ | Стоимость |
|------|-----|-----------|
| **−1** к ЧЦ брони | **9** | **¼** слитка |
| **Сломано** оружие | **10** | **½** слитка |
| **Двемерское** | **11** | шестерёнки **×2** |

На **дороге** без наковальни: **−2** к итогу ремонта.

---

## 5. Зачарование

| Этап | Действие |
|------|----------|
| **1** | **Разобрать** зачарованный предмет → узнать **эффект** (**2d6 + Зачарование ≥ 10**) |
| **2** | **Зарядить** камень душ (убийство **магическим** / сильным врагом) |
| **3** | **Алтарь** — **2d6 + Зачарование ≥ ЧЦ** эффекта |
| **4** | Предмет получает **1** эффект; камень **трескается** |

### Эффекты (ЧЦ наложения)

| Эффект | ЧЦ | Срабатывание |
|--------|-----|--------------|
| **Огонь / мороз / шок** | **11** | раз за сцену **+1** к **итогу** атаки |
| **Поглощение здоровья** | **12** | при убийстве **снять 1 стресс** |
| **Поглощение маны** | **12** | при попадании по магу **+1** мана |
| **Паралич** | **13** | **≥ 12 + Воля** цели, 1 раунд |
| **Устойчивость к магии** | **12** | **+1 к ЧЦ** против заклинаний |
| **Скрытность** | **11** | **+1** к **Скрытности** |
| **Воровство** | **11** | **+1** к **Карманной краже** |

**Душа:** **пустая** — только заряд; **чёрная** — **+1** к ЧЦ наложения, **1 стресс** кузнецу-зачарователю.

---

## 6. Станки и локации

| Станок | Где | Бонус |
|--------|-----|-------|
| **Наковальня** | любой кузнец | — |
| **Кузня Вайтрана** | Адрианн | **−1** ЧЦ сталь |
| **Кузня Скайрим** | Виндхельм | **−1** ЧЦ нордское |
| **Кузня гильдии** | Рифтен | **−1** ЧЦ лёгкая броня |
| **Алтарь зачарования** | Коллегия | **−1** ЧЦ зачарования |
| **Кузня даэдра** | квест Мехруинеса | даэдрическая ковка |

---

## 7. Перки (см. таланты)

| Перк | Эффект |
|------|--------|
| **Стальной кузнец** | сталь / железо **−1** ЧЦ |
| **Двемерский кузнец** | двемер **−1** ЧЦ |
| **Оружейник** | оружие **+1** к бонусу при **успешной** ковке **≥ ЧЦ + 2** |
| **Бронник** | броня **+1** к ЧЦ при том же |
| **Зачарователь** | **2** эффекта на предмет (второй **+2** ЧЦ) |

---

## Пример из партии: «Белый берег»

**Эорлунд** улучшает **стальной** топор Ульфрика до **II**: **3** стали, **2d6 + Кузнечное 3 = 12** против ЧЦ **11** → топор **+1** бонус (итого **+3** с материалом и типом).
