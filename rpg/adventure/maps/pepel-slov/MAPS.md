# Карты «Пепел слов»

**10 battlemap** + **обложка** для [«Пепел слов»](../../03-pepel-slov.html). Стиль — бетон, ржавчина, оранжевый акцент огня, голубое свечение экранов.

**Обложка (препресс):** [`cover.png`](cover.png) · перегенерация: `npm run build:adventure-covers`

Маркеры **A / B / C** — ключевые точки сцены (NPC, улики, выходы). Нажмите на изображение, чтобы открыть в полном размере.
