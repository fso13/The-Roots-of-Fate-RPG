# Словарь терминов

Краткие определения сокращений «Корней судьбы». В тексте правил они **подчёркнуты пунктиром** — наведите курсор для подсказки или перейдите по ссылке.

<a id="term-chc"></a>

## ЧЦ

**Число цели.** Порог, который нужно **достичь или превзойти** при броске (`светлый + тёмный + модификаторы ≥ ЧЦ`). Шкала хранителя: тривиально **7**, легко **8–9**, обычно **10–11**, трудно **12–13**, опасно **14–15**, экстремально **16–17**, легендарно **18+** (см. [главу 1](00-yadro.md)).

**ЧЦ защиты** — то же число для отражения атаки: **8 + Ловкость + доспех (+ щит)**.

<a id="term-od"></a>

## ОД

**Очки действия.** Ресурс хода в бою. Обычно **2 ОД** за раунд; тратятся на атаку, сдвиг по дистанции и особые действия (см. [главу 2](02-boy.md)).

<a id="term-oo"></a>

## ОО

**Очки опыта.** Награда между сессиями за достигнутые цели. Тратятся на **узлы деревьев** и **ранги навыков** (см. [главу 3](03-derevya-talantov.md), [главу 6](09-sozdanie-i-uroven.md)).

<a id="term-d6"></a>

## d6

**Шестигранный кубик.** Единственный тип кубиков за столом (см. [главу 1](00-yadro.md)).

<a id="term-2d6"></a>

## 2d6

**Два d6.** Стандартный бросок проверки: **светлый** и **тёмный**; **суммируйте** грани, затем прибавьте модификаторы. При успехе читают светлый, при провале — тёмный (см. [главу 1](00-yadro.md)).

<a id="term-svetlyy"></a>

## Светлый кубик

Один из двух d6 проверки навыков / сцен. Участвует в сумме против ЧЦ; при **успехе** по его грани читают **степень успеха** (едва → идеально).

<a id="term-temnyy"></a>

## Тёмный кубик

Второй d6 проверки навыков / сцен. Участвует в сумме против ЧЦ; при **провале** по его грани читают **цену** и обязательный **шаг вперёд** (провал без прогресса запрещён).

<a id="term-1d6"></a>

## 1d6

**Один d6.** Один шестигранник — для таблиц, случайного выбора, дополнительных эффектов.

## Дистанции

| Термин | Значение |
|--------|----------|
| **Даль** | Дальняя дистанция боя |
| **Рядом** | Средняя дистанция |
| **Рукопашная** | Ближняя дистанция, контакт |
