# Словарь терминов

Краткие определения сокращений «Корней судьбы». В тексте правил они **подчёркнуты пунктиром** — наведите курсор для подсказки или перейдите по ссылке.

<a id="term-chc"></a>

## ЧЦ

**Число цели.** Порог, который нужно **достичь или превзойти** при броске (`2d6 + модификаторы ≥ ЧЦ`). Задаёт хранитель: простая задача 8–10, средняя 11–13, сложная 14–16, экстремальная 17+.

**ЧЦ защиты** — то же число для отражения атаки: **8 + Ловкость + доспех (+ щит)**.

<a id="term-od"></a>

## ОД

**Очки действия.** Ресурс хода в бою. У персонажа обычно **2 ОД** за раунд; тратятся на атаку, сдвиг по дистанции и особые действия (см. [Глава 2. Бой (модуль)](02-boy.md)).

<a id="term-oo"></a>

## ОО

**Очки опыта.** Награда между сессиями за достигнутые цели. Тратятся на **узлы деревьев** и **ранги навыков** (см. [Глава 3. Деревья талантов](03-derevya-talantov.md), [Глава 6. Создание персонажа](09-sozdanie-i-uroven.md)).

<a id="term-d6"></a>

## d6

**Шестигранный кубик.** Единственный тип кубиков за столом в «Корнях судьбы» (см. [Глава 1. Ядро системы](00-yadro.md)).

<a id="term-2d6"></a>

## 2d6

**Два d6.** Стандартный бросок проверки: бросьте **два** шестигранника и **суммируйте** результат, затем прибавьте модификаторы.

<a id="term-1d6"></a>

## 1d6

**Один d6.** Один шестигранник — для таблиц, случайного выбора, дополнительных эффектов.
