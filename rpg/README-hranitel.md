# «Корни судьбы» — Книга хранителя

Правила для ведущего: модули, бестиарий, опциональные системы, приключения. Игрокам достаточно [Книги игрока](README-igrok.md).

Система использует **только d6**.

## Быстрый старт

1. Скопируйте `modules/manifest.example.yaml` в `manifest.yaml` и отметьте модули (**rany**, **crits** — по желанию).
2. Раздайте игрокам [Книгу игрока](README-igrok.md) или ссылку на сайт.
3. Стартовое приключение — [«Стеклянный звон»](adventure/01-steklyannyy-zvon.md).

Партия-пример: **«Стеклянные волки»**, Торнвельд.
