# Глава 1. Модульность

## 1. Что такое модуль

**Модуль** — согласованный пакет правил (один или несколько файлов), который можно **включить** или **выключить** без переписывания ядра. Ядро (глава 1, книга игрока) остаётся общим; модули добавляют слои: тактический бой, магия, расширенное снаряжение, бестиарий и т.д.

## 2. Манифест кампании

В начале кампании создаётся файл **`manifest.yaml`** (шаблон: `modules/manifest.example.yaml`):

- **`modules`** — словарь «имя модуля → true/false».
- **`custom_modules`** — список путей к вашим папкам с правилами и флаги `enabled`.

Если модуль **выключен**, его главы не используются; хранитель не предлагает связанные с ним опции, если только стол не договорится о «дом правил».

## 3. Как сделать свой модуль

1. Создайте папку, например `my_modules/название/`.
2. Положите туда **`module.md`** с заголовком, зависимостями и разделами правил в том же стиле, что и официальные главы.
3. Укажите в начале файла блок метаданных:

```yaml
---
id: sea_faring
requires: [core, equipment]
replaces: []
dice_notes: "Все новые броски — только d6."
---
```

4. Добавьте путь в `custom_modules` манифеста и `enabled: true`.

**Правила совместимости:** любой новый бросок переводите в **d6** (см. главу 0).

## 4. Приоритет конфликтов

При противоречии: **ядро** → **включённые официальные модули** (в порядке важности в `manifest`) → **кастомные модули** (в порядке в списке). Стол может явно переопределить одну строку правил голосованием.

---

## Пример из партии: «Стеклянные волки», подготовка

Группа включает **magic**, **tactical_combat**, **equipment**, **bestiary**, **character_progression**; для «лёгкого» боя не включает **wounds** и **crits_and_fumbles** — меньше таблиц. Фэнтези-флаги **fantasy_*** оставляют включёнными. Лин копирует манифест и правит флаги.

**Орён** (игрок): «Добавим домашний модуль — „Культы стекла“ — только флаги и ритуалы?» Лин создаёт `my_modules/glass_cults/module.md`, подключает в `custom_modules`. На сессии 1 при спорных ситуациях сначала читают ядро, потом магию, потом домашний модуль — так стол не ломает единую шкалу d6.

# Глава 2. Бестиарий

*Требует ядро и модуль боя. ЧЦ защиты монстров: **8 + Ловкость + доспех** (как у героев). Расширенный фэнтези-бестиарий — отдельный модуль: [«Фэнтези-бестиарий»](modules/fantasy-bestiariy.html).*

## 1. Как читать запись

| Поле | Значение |
|------|----------|
| **Угроза** | сложность сцены (нарратив) |
| **Тело / Ловкость / Разум / Воля** | атрибуты |
| **Раны** | максимум ран до падения |
| **Стресс** | максимум стресса (если используете) |
| **Оружие** | бонус **+N** в формуле **(итог атаки − ЧЦ) + N** |
| **Особое** | 1–2 особенности, не больше |

Все броски — **d6**.

## 2. Шаблоны существ

### Городская стража (человек)

- **Угроза:** низкая  
- **Тело 3, Ловкость 2, Разум 2, Воля 2**  
- **Раны 8, Стресс 6**  
- **Копьё +2**, доспех кожа (+1 к ЧЦ защиты)  
- **Особое:** без командира в бою действует осторожнее — ведущий может дать им **−1** к первой атаке в сцене.

### Гарпия-налётчица

- **Угроза:** средняя  
- **Тело 2, Ловкость 4, Разум 1, Воля 2**  
- **Раны 7, Стресс 8**  
- **Когти** +1 (рукопашная), **дальняя атака** перьями +1  
- **ЧЦ защиты:** 8 + 4 + 0 = **12** (без доспеха)  
- **Особое:** раз за сцену **бесплатный сдвиг** на одну дистанцию (Рядом ↔ Рукопашная ↔ Даль) — **0 ОД** один раз.

### Стеклянный волк (конструкт)

- **Угроза:** средняя–высокая  
- **Тело 4, Ловкость 3, Разум 0, Воля 1**  
- **Раны 10**, стресс не используется  
- **Укус** +2, **ЧЦ защиты** +1 (твёрдая шкура)  
- **Слабость:** резонанс **школы Дух** (гром, чистая сила) — при провале **2d6 + Воля ≥ 12** волк в следующем раунде получает только **1 ОД**.

### Торнвельдский слизень (босс-мини)

- **Угроза:** высокая  
- **Тело 5, Ловкость 1, Разум 0, Воля 2**  
- **Раны 18**  
- **Псевдоподы** +2, дистанция **Рукопашная** ко всем в «комнате» слизня  
- **Особое:** раз в **2 раунда** **залп кислоты** по **всем в Рукопашной** — **2d6 + Тело ≥ 13** или **1 рана** (не атака по ЧЦ, отдельная проверка).

## 3. Создание своих существ

1. Атрибуты и **одна** яркая способность.  
2. **ЧЦ защиты** считайте как у персонажа.  
3. Все броски — **d6**.

---

## Пример из партии: «Стеклянные волки»

**Гарр** держит мост: гарпия в **Даль** стреляет перьями по **Мире** — **дальняя атака** по ЧЦ **12**. **Кай** в **Рукопашной** с гарпией бьёт кинжалом.

**Стеклянный волк:** **Орён** использует заклинание **Духа** (разряд/резонанс) — по слабости волк на раунд ослаблен (**1 ОД**).

# Глава 4. Получение и учёт ран

*Опционально. Требует ядро; для боя — [Глава 2. Бой (модуль)](#02-boymd). Расширение: **ранения частей тела** — по желанию стола.*

Число **нанесённых ран** за атаку = **урон** по формуле главы 2: **(итог атаки − ЧЦ защиты) + бонус оружия** (и модификаторы критов, если включены).

Если модуль **выключен**, при попадании просто отнимайте **раны** как единый ресурс (как в главе 0) без дополнительных правил.

## 1. Полоска ран

**Максимум ран** = **6 + Тело** (или **4 + Тело** для «мягкой» кампании). При **0 ран** персонаж **выбит**: без сознания или смерть — по договорённости стола.

## 2. Типы ран (по желанию)

Когда атака наносит урон, ведущий или атакующий помечает **тип** (для ролевого эффекта):

| Тип | Пример последствия (нарратив, не стакается без модуля критов) |
|-----|----------------------------------------------------------------|
| **Лёгкая** | царапина, −0 к броскам |
| **Тяжёлая** | шок: до конца сцены **−1** к первому броску Тела |
| **Критическая** | только если сработала [Глава 5. Критические попадания и промахи](#глава-5-критические-попадания-и-промахи) или особое оружие |

Игроки могут **игнорировать** типы и вести только число — модуль всё равно полезен для «сколько до падения».

## 3. Стабилизация (общий урон)

Вне боя или **1 ОД** в бою: проверка **2d6 + Разум + «Медицина»** (или Тело + Выживание) **≥ 10** — **снять 1 рану** у союзника **Рукопашная/Рядом** (не у себя без талантов).

---

## 4. Ранения частей тела *(опционально)*

Используйте, если хотите **не только** общую полоску, но и **руки, ноги, голову**.

### 4.1. Зоны удара

| **1d6** | Часть тела |
|---------|------------|
| **1** | **Голова** |
| **2** | **Грудь / спина** (торс) |
| **3** | **Рука с оружием** (ведущая) |
| **4** | **Другая рука** |
| **5** | **Нога** (ведущая / опорная) |
| **6** | **Другая нога** |

*Существа без рук/с четырьмя лапами:* ведущий переназначает строки **3–6** (передние/задние лапы, хвост и т.д.).

### 4.2. Когда определять зону

| Способ | Как |
|--------|-----|
| **Случайно** | После **любого успешного попадания**, если стол включил локализацию: бросьте **1d6** по таблице выше. |
| **Прицельный удар** | **До** броска атаки объявите зону. **−2** к **итогу атаки** (голова: **−3**). Если попадание есть — урон считается как обычно, но **последствие** (п. 4.3) применяется **к этой** зоне и на **одну ступень суровее** (см. ниже). |
| **Крит по модулю [Глава 5. Критические попадания и промахи](#глава-5-критические-попадания-и-промахи)** | Можно бросить зону и дать **дополнительный** эффект по зоне без прицела. |
| **Удобное правило** | Локализацию бросаете **только** если урон **≥ 3** за удар **или** был прицел **или** крит — чтобы не кидать каждый раз. |

### 4.3. Состояния конечности / зоны

Одна и та же зона может быть **целой**, **повреждена**, **выведена**. Отметьте на листе.

| Состояние | Что значит |
|-----------|------------|
| **Целая** | нет штрафов |
| **Повреждена** | **−1** к проверкам, где участвует эта часть (рука — атаки/ловкость рук; нога — движение, Уклонение; голова — Разум/Воля на коротком отрезке; грудь — Тело) |
| **Выведена** | часть **недоступна**: рука роняет оружие / не держит щит; нога — **половина ОД** на **Сдвиг** или нельзя **бежать**; голова — **1 стресс** за раунд до стабилизации |

**Голова — особый случай:** второе попадание в **повреждённую** голову (или одно тяжёлое с прицелом) — ведущий может объявить **нокаут** или **смерть** (по жёсткости кампании).

**Торс:** «повреждён» = **−1** к Телу на проверках до лечения; «выведен» = персонаж **выбывает** из боя (кровотечение, шок).

### 4.4. Связь с числом ран

- **Простой вариант:** локализация — только **ролевой** штраф; **раны** снимаются с общего запаса как раньше.
- **Жёсткий вариант:** при переходе зоны в **«выведена»** дополнительно **−1** к общей полоске ран (один раз за эпизод с этой зоны).

Выберите **один** вариант на кампанию.

### 4.5. Лечение локальных ран

| Действие | Проверка / условие | Эффект |
|----------|-------------------|--------|
| **Перевязка / шина** | **1 ОД** вне боя или **2 ОД** в бою; **2d6 + Медицина ≥ 10** | **повреждена** → **целая** **или** **выведена** → **повреждена** (на выбор, одна зона) |
| **Покой и уход** | между сессиями / **длинный отдых** | все **повреждённые** зоны → **целые**, если не было **выведено** |
| **Хирургия** | **Медицина ≥ 13**, инструменты, **1 час** | **выведена** конечность без ампутации → **повреждена** |
| **Магия** | заклинания **Сотворения** (глава 4, списки) | как **сильное лечение**, часто снимает и зону, и **1–2 раны** общих |
| **Зелье лечения** | по снаряжению | обычно **+1 рана** общая; по согласованию — ещё **одна** зона на ступень вверх |

Ампутация и протезы — **нарратив** и домашние правила.

## 5. Без лишнего счёта

Не вводите одновременно **5 дебаффов**. Если нужен штраф — один на сцену на персонажа **или** одна зона в фокусе.

---

## Пример из партии: «Стеклянные волки»

У **Миры** **2 раны** из **9**. **Гарр** стабилизирует: **Медицина**, снимает **1 рану**.

В другой сцене **Кай** получает прицельный удар в **ногу** (**−2** к итогу атаки врага, но попал). Зона **нога** → **повреждена**; Кай **−1** к первому **Сдвигу** в сцене. Между боями **перевязка** снимает пометку.

# Глава 5. Критические попадания и промахи

*Опционально. Требует ядро. Все броски — d6.*

## 1. Базовое правило (пара кубиков)

После броска **2d6** в **атаке** смотрите пары граней:

| Результат обоих кубиков | Эффект (база) |
|-------------------------|----------------|
| **6+6** | **Крит** — **таблица критов** (раздел 3) |
| **1+1** | **Провал** — **таблица провалов** (раздел 4) |

## 2. Заклинания-атаки

Тот же взгляд на **кубики броска атаки** магии (глава 4): при **6+6** / **1+1** применяйте таблицы; эффекты **«оружие»** читайте как **заклинание** (отдача = **1 стресс** или **1 искра**).

## 3. Таблица критов *(при двух максимумах)*

Сначала считают **обычный урон** по формуле главы 2. Затем бросьте **1d6** и примените **дополнительно** (или выберите строку без броска — по договорённости):

| **1d6** | Дополнительный эффект крита |
|---------|-----------------------------|
| **1** | **+2** к итоговому урону (простой крит) |
| **2** | **+1** к урону и цель **смещается** на **Рядом** (опрокид, отброс) |
| **3** | **Разоружение:** цель роняет оружие (или щит) — **1 ОД** поднять в следующем раунде |
| **4** | Цель получает **1 стресс** (оглушение, боль) |
| **5** | Бросок **зоны** по [Глава 4. Получение и учёт ран](#глава-4-получение-и-учёт-ран), раздел 4 — к этой зоне примените **повреждена** сразу (если модуль ран с зонами включён) |
| **6** | **+1** к урону **и** выберите любой эффект из **1–4** (игрок или ведущий для NPC) |

*Если модуль зон ран **не** используется:* строка **5** = **+2** к урону вместо зоны.

## 4. Таблица провалов *(при двух минимумах)*

| **1d6** | Эффект провала |
|---------|------------------|
| **1** | Полный **промах** — атака не попадает, даже если сумма ≥ ЧЦ |
| **2** | Промах **и** вы **−1 ОД** в **следующем** раунде (замах, усталость) |
| **3** | Атака попадает **в вас** на **половину** округлённого **вниз** вашего бонуса оружия (минимум **1** урон) — «отдача», удар об пол |
| **4** | **Оружие выпало:** **1 ОД** чтобы поднять в **Рукопашной** (или **Рядом** к оружию) |
| **5** | Случайный союзник в **Рядом** с вами получает **1** урон (дружественный огонь) — если некого, повторите **1d6** |
| **6** | Вы **падаете**: сместитесь на **Рядом** от ближайшего врага и **−1** к **первой** защите до вашего хода |

*Дальняя атака:* строки **3–4** замените на: **3** — **1** урон (тетива, обжог); **4** — **нет стрел** в этом выстреле (расход слота) или **−1** к следующей дальней атаке.

## 5. «Почти крит / почти провал» *(опционально)*

| Кубики | Эффект |
|--------|--------|
| **5+6** или **6+5** | **Лёгкий крит:** **+1** к урону **или** перебросьте **один** d6 атаки (если ещё не объявлен итог) |
| **1+2** или **2+1** | **Заминка:** **−1** к **итогу** этой атаки (ещё до сравнения с ЧЦ) |

Отключите, если хотите только «чистые» 6+6 и 1+1.

## 6. Опция «мягче»

- **1+1** → **−2 к итоговому урону** вместо таблицы провалов (или один бросок **1d6** на таблице).
- **6+6** → только **+1** к урону без таблицы критов.

---

## Пример из партии: «Стеклянные волки»

**Кай** на рукопашную: **6 и 6** — крит. Урон по формуле, затем **1d6 = 4** — цель **1 стресс**.

**Гарпия** бросает **1 и 1** — **1d6 = 1** — чистый промах.

# Глава 6. Бой с отрядами

*Опционально. Требует: ядро, модуль боя [Глава 2. Бой (модуль)](#02-boymd), бестиарий [Глава 2. Бестиарий](#глава-2-бестиарий).*

**Отряд** — группа одинаковых существ одного типа (например, 3 бандита, 5 скелетов). У них общий пул ран, они атакуют и получают урон как единое целое. Модуль сокращает счётчики и кубики в массовых стычках.

---

## 1. Что такое отряд

- **Тип:** один шаблон существа из бестиария (бандит, скелет-воин, ополченец и т.д.).
- **Численность (N):** 2–6 существ в группе. Одно существо — не отряд, действует по обычным правилам.
- **Раны отряда:** `Раны одного × N` (итоговый пул до «падения» всей группы).

*Пример:* 3 бандита по 7 ран → отряд из **21 раны**.

---

## 2. Атака отряда

Отряд бьёт **одним заходом** за раунд — один бросок атаки.

### Бросок атаки

`2d6 + атрибут(ы) из шаблона + ранг (если у существа)` ≥ **ЧЦ защиты** цели.

Используются атрибуты **одного** существа (как в шаблоне): отряд атакует «массой», но бросок один.

### Урон от отряда

**Урон = (итог атаки − ЧЦ защиты) + бонус оружия + бонус за численность.**

| Численность N | Бонус за численность |
|---------------|----------------------|
| 2             | +0                   |
| 3             | +1                   |
| 4             | +2                   |
| 5             | +3                   |
| 6             | +3 (потолок)         |

*Логика:* больше рук — выше шанс пробить защиту; лишние бонусы обрезаны, чтобы не ломать баланс.

---

## 3. Получение урона отрядом

Любая **успешная атака** по отряду наносит урон **всему** пулу ран отряда.

- Урон вычитается из **общего** пула ран.
- При **0 ран** отряд считается побеждённым: все пали, разбежались или сдались — по договорённости стола.

Не нужно выбирать «кого именно» бьют: считается, что удары рассеиваются по группе.

---

## 4. Разделение отряда

Если отряд или часть его оказывается в разных зонах (например, часть погналась, часть осталась), ведущий может объявить **разделение** отряда. Либо игрок может **инициативно** попытаться оттянуть часть врагов.

### Действия персонажа для провоцирования разделения

| Действие                | ОД  | Описание |
|-------------------------|-----|----------|
| **Отвлечь часть отряда**| 1 ОД| Крик, бросок камня, отход в сторону и т.п. — опишите, как вы отвлекаете врагов. Проверка **2d6 + Воля** (или **Хитрость**, если навык есть) **≥ 10**. Успех: 1–2 существа отделяются — ведущий создаёт **второй мини-отряд** или заставляет их преследовать вас отдельно. |
| **Зажать в узкости**    | 1–2 ОД| Переход в узкий проход, к двери, на мост. Ведущий решает: при успешном занятии позиции отряд физически не может атаковать всеми сразу — часть «ждать своей очереди». Можно считать это как отряд с эффективной численностью **−1** к бонусу за численность при атаке (минимум 0). |
| **Вклиниться в строй**  | 1 ОД| Зайти в гущу отряда (Рукопашная), чтобы враги мешали друг другу. Риск: вы под обстрелом всей группы. **Бонус:** отряд получает **−1** к итогу своей следующей атаки (давка, помехи). |
| **Разделить огнём**     | 1 ОД| Дальняя атака или заклинание по отряду с явной целью «разогнать». При нанесении **≥ половины ран одного существа** (округляя вверх) за один удар — ведущий может позволить 1 существу **отделиться** (раненый отстал, отполз) и далее считать его как отдельную цель или мини-отряд из 1. |

### Если отряд уже разделился (по инициативе ведущего)

- Создаются **два (или более) отряда** с меньшей численностью.
- Раны делятся **пропорционально**: например, отряд из 4 (20 ран) разделился на 2+2 → два отряда по 2 существа, по 10 ран каждый.
- Каждый меньший отряд действует по своим правилам: свой ход, свой бросок атаки, свой пул ран.

---

## 5. Дистанция к отряду

К **отряду** применяются те же зоны, что к одной цели:

- **Рукопашная** — можно бить оружием ближнего боя.
- **Рядом** — 1 ОД до Рукопашной.
- **Даль** — лук, метательное, дальняя магия.

Ведущий определяет, в какой зоне отряд находится относительно персонажей. Один отряд — одна «точка» для дистанции.

---

## 6. Инициатива и ход отряда

Отряд участвует в инициативе **один раз**: `2d6 + Ловкость` (из шаблона существа). У отряда **2 ОД** в раунде — как у обычного существа. Тратит их на атаку и сдвиг по тем же правилам.

---

## 7. Краткая шпаргалка

| Параметр        | Формула |
|-----------------|---------|
| Раны отряда     | Раны одного × N |
| Атака отряда    | 1 бросок, атрибуты из шаблона |
| Урон от отряда  | (итог − ЧЦ) + оружие + бонус за N (см. таблицу) |
| Урон по отряду  | Вычитается из общего пула ран |

---

## Пример: 3 бандита против партии

**Бандит** (шаблон): Тело 3, Ловкость 2, Раны 7, Кинжал +1, ЧЦ 10.

**Отряд:** 3 бандита → 21 рана, бонус за численность +1.

Партия: **Кай** и **Гарр** в Рукопашной с отрядом, **Мира** в Даль (лук).

**Ход отряда:** бросок атаки по Каю — `2d6 + 3 + 1` = 11. ЧЦ Кая 10. Попадание. Урон = (11−10) + 1 (кинжал) + 1 (численность) = **3 раны**.

**Ход Кая:** атака по отряду — итог 14, ЧЦ 10. Урон = (14−10) + 2 (меч) = **6 ран**. Отряд: 21 − 6 = **15 ран** осталось.

**Мира** описывает: «Кричу и отбегаю к выходу». Тратит 1 ОД на **Отвлечь часть отряда**. Бросок Воля: 2d6+2 = 11 ≥ 10. Успех — 1 бандит отделяется, догоняет Миру. Ведущий создаёт мини-отряд «1 бандит» (7 ран) у Миры и основной отряд «2 бандита» (14 ран) у Кая и Гарра.

# Словарь терминов

Краткие определения сокращений «Корней судьбы». В тексте правил они **подчёркнуты пунктиром** — наведите курсор для подсказки или перейдите по ссылке.

<a id="term-chc"></a>

## ЧЦ

**Число цели.** Порог, который нужно **достичь или превзойти** при броске (`2d6 + модификаторы ≥ ЧЦ`). Задаёт хранитель: простая задача 8–10, средняя 11–13, сложная 14–16, экстремальная 17+.

**ЧЦ защиты** — то же число для отражения атаки: **8 + Ловкость + доспех (+ щит)**.

<a id="term-od"></a>

## ОД

**Очки действия.** Ресурс хода в бою. У персонажа обычно **2 ОД** за раунд; тратятся на атаку, сдвиг по дистанции и особые действия (см. [Глава 2. Бой (модуль)](#02-boymd)).

<a id="term-oo"></a>

## ОО

**Очки опыта.** Награда между сессиями за достигнутые цели. Тратятся на **узлы деревьев** и **ранги навыков** (см. [Глава 3. Деревья талантов](#03-derevya-talantovmd), [Глава 6. Создание персонажа](#09-sozdanie-i-urovenmd)).

<a id="term-d6"></a>

## d6

**Шестигранный кубик.** Единственный тип кубиков за столом в «Корнях судьбы» (см. [Глава 1. Ядро системы](#00-yadromd)).

<a id="term-2d6"></a>

## 2d6

**Два d6.** Стандартный бросок проверки: бросьте **два** шестигранника и **суммируйте** результат, затем прибавьте модификаторы.

<a id="term-1d6"></a>

## 1d6

**Один d6.** Один шестигранник — для таблиц, случайного выбора, дополнительных эффектов.
