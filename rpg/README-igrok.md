# «Корни судьбы» — Книга игрока

Всё, что нужно за столом игроку: ядро, бой, персонаж, магия, снаряжение и фэнтези-справочники. Правила для хранителя — в [Книге хранителя](README-hranitel.md).

За столом нужны **только d6**. Другие кубики не понадобятся.

## Быстрый старт

1. Возьмите **d6**.
2. Пролистайте **правила в комиксах** на сайте (`pravila-komiks.html`) или [главу 1](00-yadro.md).
3. Создайте персонажа по [главе 6](09-sozdanie-i-uroven.md). На сайте есть **интерактивный лист**.
4. Хранитель включает модули по [Книге хранителя](README-hranitel.md).

Партия-пример в правилах: **«Стеклянные волки»**, Торнвельд.
