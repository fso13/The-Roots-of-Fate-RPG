# «Корни судьбы» — Книга игрока

Всё, что нужно игроку за столом: ядро, бой, персонаж, магия, снаряжение и фэнтези-справочники. Правила для хранителя — в [Книге хранителя](README-hranitel.md).

Система использует **только d6**. Другие кубики не нужны.

## Быстрый старт

1. Возьмите **d6** — других кубиков не нужно.
2. Создание персонажа — [Глава 6. Создание персонажа и рост уровня](09-sozdanie-i-uroven.md). **Интерактивный лист персонажа** — на сайте.
3. Хранитель настраивает модули по [Книге хранителя](README-hranitel.md).

Партия-пример: **«Стеклянные волки»**, Торнвельд.
