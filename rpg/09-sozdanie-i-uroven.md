# Глава 6. Создание персонажа и рост уровня

*Требует ядро. Рекомендуется: [глава 3](03-derevya-talantov.md), фэнтези-модули.*

Как собрать персонажа к первой сессии и что даёт повышение уровня.

## 1. Создание персонажа

### Шаг 1. Концепт

Имя, происхождение, цель — свободно.

### Шаг 2. Атрибуты

Четыре атрибута: **Тело, Ловкость, Разум, Воля**. Каждый **от 1 до 5** на старте. Выберите один способ:

**Вариант А. Броски.** Бросьте **4 × 2d6** (по одному на каждый атрибут) и переведите по таблице:

| Сумма 2d6 | Значение атрибута |
|-----------|-------------------|
| 2–4 | 1 |
| 5–6 | 2 |
| 7–8 | 3 |
| 9–10 | 4 |
| 11–12 | 5 |

**Вариант Б. Очки.** У вас **10 очков**. Стоимость значения:

| Значение | Стоимость |
|----------|-----------|
| 1 | 0 |
| 2 | 1 |
| 3 | 2 |
| 4 | 4 |
| 5 | 6 |

Например: значение **4** стоит **4 очка**; раздать 4/3/2/1 = 10 очков.

### Шаг 3. Навыки

- Выберите **один навык** с **рангом 2**, **два навыка** с **рангом 1**, остальные **0** (из списка ядра или расширенного — [глава 9](fantasy/02-talanty-i-navyki.md)).
- Если включена **магия**: добавьте **«Магия»** ранг **1** *или* возьмите узел «Первое соглашение» (глава 4) — по правилам кампании.

### Шаг 4. Таланты / дерево

Если включён модуль деревьев: **один стартовый узел** ранга **I** по выбранному архетипу **бесплатно** (или за **3 ОО** с нуля — жёсткий вариант).

### Шаг 5. Ресурсы

- **Стресс макс.** = **6 + Тело** (или по модулю ран).
- **Раны макс.** = **6 + Тело** (или [раны](07-rany.md) в книге хранителя).
- **Искры** (если магия): **3 + Воля**.

### Шаг 6. Снаряжение

Старт: **одно** оружие по деньгам кампании, **доспех** в рамках допуска хранителя, **набор путешественника** (верёвка, фляга, огниво) + **3 мелких предмета**. Подробнее — глава 5 и [глава 10](fantasy/03-snaryazhenie.md).

## 2. Уровень и рост

**Уровень** персонажа — от **1** вверх. После **значимой вехи** (конец арки, 2–4 сессии — решает хранитель) проводится **повышение уровня**.

### Что даёт +1 уровень

| Получаете | Количество |
|-----------|------------|
| **Очки опыта (ОО)** | **3 ОО** за уровень (фикс) *или* **2 + бонус** за ролевую цель — по договорённости |
| **Атрибут** | **один раз на всю кампанию на 4-м и 8-м уровне** (пример): +1 к одному атрибуту (не выше 5 без особых правил) |
| **Навык** | **+1 ранг** к одному навыку (не выше максимума 4; узлы дерева могут поднять потолок) |
| **Талант** | тратите **ОО** на узлы дерева — см. главу 3 |
| **Магия** | при повышении уровня можно вложить ОО в **узел школы**; искры **+0** сами по себе, но узлы могут увеличить максимум искр (если так решено в гл. 4) |

> **Упрощение.** На каждом уровне: **3 ОО + один бесплатный ранг навыка** (без покупки ОО за него). Атрибуты — реже.

### Таблица (пример прогрессии)

| Уровень | ОО за веху | Заметка |
|---------|------------|---------|
| 1 | — | создание |
| 2 | 3 ОО | первый ап |
| 3 | 3 ОО | |
| 4 | 3 ОО + **+1 атрибут** | по опции выше |
| … | … | |

Хранитель может заменить **уровни** на **только ОО** без цифры уровня — тогда эту главу читайте как «что даёт пакет ОО».

## Пример из партии: «Стеклянные волки»

Группа закрыла главу о канале. Хранитель объявляет **уровень 2**.

**Кай** получает **3 ОО**, тратит **2** на узел **«Тихий шаг II»**, **1** копит. Бесплатно кладёт **+1 ранг** в **«Скрытность»** (1→2).

**Мира** кладёт бесплатный ранг в **«История»**, **3 ОО** откладывает на магический узел (покупка позже).
