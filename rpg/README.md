## PDF

Полная книга правил в PDF собирается из этих же `.md` файлов (из корня репозитория):

```bash
npm run pdf
```

- Обычный: `public/koreni-sudby-pravila.pdf` — `npm run pdf`
- В стиле Cairn (A5, Lora): `public/koreni-sudby-pravila-cairn.pdf` — `npm run pdf:cairn`

## Быстрый старт

1. Выберите **тип кубика** (рекомендация: **d6**).
2. Скопируйте `modules/manifest.example.yaml` в `manifest.yaml` и отметьте модули (**rany**, **crits** — по желанию).
3. Создание персонажа — [Создание персонажа и рост уровня](09-sozdanie-i-uroven.md). **Интерактивный лист персонажа** — на сайте (раздел «Лист персонажа»).

Партия-пример: **«Стеклянные волки»**, Торнвельд.
