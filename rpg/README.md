Правила разделены на две книги — как в классических ролевых системах:

## Сборка книг

| Команда | Файл |
|---------|------|
| `npm run book:igrok` | `rpg/kniga-igroka.md` |
| `npm run book:hranitel` | `rpg/kniga-hranitelya.md` |
| `npm run book:md` | `rpg/kniga-polnaya.md` — полное издание |
| `npm run book:homebrewery` | `rpg/kniga-homebrewery.md` |

## PDF

```bash
npm run pdf:igrok          # koreni-sudby-kniga-igroka.pdf
npm run pdf:hranitel       # koreni-sudby-kniga-hranitelya.pdf
npm run pdf:polnoe         # koreni-sudby-polnoe-izdanie.pdf
npm run pdf:cairn:igrok    # …-cairn.pdf (A5, стиль Cairn)
npm run pdf:all            # все шесть PDF
```

## Быстрый старт

1. Возьмите **d6**.
2. Игроки — [Книга игрока](README-igrok.md); хранитель — [Книга хранителя](README-hranitel.md).
3. Скопируйте `modules/manifest.example.yaml` в `manifest.yaml`.
4. **Лист персонажа** — на сайте.

Партия-пример: **«Стеклянные волки»**, Торнвельд.
